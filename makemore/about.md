# About this directory

This is a replication of Andrej Karpathy's makemore from scratch as an attempt to increase understanding of neural nets, transformers and language models

Makemore is a character level language architecture that generates a single word as an output

## Models
1. makemore_bigram.py : bigram based model
2. makemore_bigram_nn.py : bigram based nn model -- though it would not be like conventional nn as the depth of network would be shallow as the nn works as a bigram network with weights actually representing probabilities
